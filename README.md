# Capacity-Expansion_4G_2G
Hello
Our network has L900 layer with 5 MHZ. The overall experiene poor for L900 layer as its only 5 Mhz. 
So we have decided to increases L900 Bandwidth from 5 MHz to 10 Mhz to improve user experiecne.
But we have to decrease our GSM capcity (Reduce G900 Freq) for increasing  L900 BW to 10 Mhz.

Please note that, we have also 20 mHz 1800 band which fullly allocated to LTE only. So, we will use 
Guad band of L1800 band as GSM 1800 frequency to incraese and balacne GSM capcity and maintain GSM voice QoS. 
Now, in our network G1800 freq is very less as voice demand not that much. So we could start G1800 plan easily.
